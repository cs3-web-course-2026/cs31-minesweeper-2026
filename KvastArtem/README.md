# Minesweeper — практична робота №2

Кваст Артем, КС-31-1.

## Запуск

Відкрийте `index.html` у браузері. Сервер, збірка та сторонні бібліотеки для гри не потрібні.

## Реалізація

- Поле 10 × 10 з 15 випадково розміщеними мінами без повторень.
- `gameState` з параметрами, статусом і часом; `board` з об'єктами клітинок.
- Підрахунок восьми сусідів, рекурсивне відкриття порожніх областей.
- Лівий клік відкриває клітинку, правий ставить або знімає прапорець.
- Ліміт 15 прапорців; відкрита клітинка не позначається прапорцем.
- Таймер починається з першої результативної дії та зупиняється при завершенні.
- Перемога після відкриття всіх 85 безпечних клітинок; поразка при відкритті міни.
- Після поразки показуються міни, підірвана клітинка та помилкові прапорці.
- Кнопка «Рестарт» скидає поле, прапорці й таймер без перезавантаження.
- Клавіатура: стрілки ↑ ↓ ← → для вибору клітинки, Enter/пробіл для відкриття, F для прапорця.
- Поле має одну зупинку Tab: далі клітинки обираються стрілками; на краях фокус не переходить в інший рядок.
- Довідка «Керування» початково згорнута й доступна на будь-якій ширині.
- Утримання F змінює прапорець один раз; Ctrl+F, Command+F та Alt+F зберігають поведінку браузера.
- Після повернення через кеш кнопкою «Назад» активний таймер продовжує роботу; новий або завершений раунд не запускається.

Оформлення продовжує інтерфейс з лабораторної №1. Її вихідна статична версія
зберігається в історії репозиторію (PR #24).

## Перевірки

З кореня репозиторію:

```sh
node KvastArtem/tests/logic.test.cjs
```

13 сценаріїв перевіряють генерацію, незалежний підрахунок сусідів на 100 полях,
рекурсію, прапорці, перемогу, поразку, таймер і перезапуск. Сторонні пакети не потрібні.
Тести виконують логічний шар у середовищі `node:vm` із контрольованими таймерами та явною межею запуску DOM.

Окремо проведено 20 автоматизованих браузерних перевірок у Microsoft Edge:
рендеринг DOM, правий клік і блокування контекстного меню, клавішу F,
навігацію чотирма стрілками та межі поля, одну зупинку Tab, відкриття
клавішами Enter/пробіл, рекурсію та таймер, поразку, рестарт, перемогу,
ширину 375 px, згорнуту довідку на сенсорному пристрої, модифіковану та
утримувану F, контраст цифри «1» і три сценарії повернення через кеш браузера.
Реальні знімки перевірки розміщені у `screenshots/`.
