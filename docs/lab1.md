# Практична робота №1. Дизайн та реалізація елементів UI у HTML та CSS

## Мета роботи
Опанувати основні принципи веб-дизайну та верстки інтерфейсів за допомогою технологій HTML і CSS. Навчитися створювати візуальну частину інтерактивного застосунку (на прикладі гри Minesweeper), враховуючи логіку відображення елементів та різні стани користувацького інтерфейсу.

## Завдання
Необхідно розробити візуальну частину гри Minesweeper, реалізувавши інтерфейс гри з усіма необхідними складовими.

1. У корінь репозиторію додати персональну директорію у форматі: `{ПрізвищеІм'я}`.
2. Створити файли `index.html` та `styles.css` у створеній директорії.
3. Реалізувати структуру інтерфейсу, що включає:
    * **Хедер гри:** таймер, індикатор кількості прапорців та кнопку старту (початок нової гри).
    * **Ігрове поле:** сітка з клітинками.
4. Описати в CSS різні стани клітинок:
    * Закрита / відкрита клітинка.
    * Клітинка з прапорцем (на міні та без неї).
    * Клітинка з міною (звичайна та та, на яку натиснув користувач).
5. Забезпечити адаптивність та базову візуальну привабливість інтерфейсу.

## Система оцінювання
* **Верстка хедера та елементів управління:** 1 бал (таймер, лічильник, кнопка).
* **Реалізація ігрового поля та станів клітинок:** 2 бали (правильна сітка та стилізація всіх варіацій клітинок).
* **Якість коду:** 1 бал (семантична верстка, відсутність зайвих елементів, чистота та структура CSS).
* **Проведення рецензування (Code Review):** 1 бал (аналіз коду іншого студента, конструктивні зауваження).

**Максимальна кількість балів: 5.**


> **Примітка:** Робота оцінюється лише за умови наявності звіту.

## Умови здачі
1. Реалізувати рішення у своїй директорії (`{ПрізвищеІм'я}`) у файлах `index.html` та `styles.css`.
2. Створити окрему гілку з назвою у форматі: `lab1/[Прізвище][Ім'я]-[короткий опис, напр. add-layout]`.
3. Завантажити зміни до репозиторію (commit + push) та відкрити Pull Request.
4. Пройти код-рев'ю від **викладача (обовʼязково)** та іншого студента (опціонально).
5. Провести рецензування коду іншого учасника курсу (опціонально).
6. Підготувати звіт у форматі PDF та завантажити його на платформу Moodle. Наявність звіту є обов'язковою. Шаблон звіту можна знайти в секції **"Додаткові матеріали"**.

**Звіт має містити:**
* Деталі виконання роботи (короткий опис процесу).
* Посилання на ваш Pull Request у GitHub репозиторії групи.
* Посилання на Pull Request іншого студента, для якого ви провели ревю коду (опціонально).
